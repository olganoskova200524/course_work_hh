# Поиск вакансий с hh.ru и сохранение в PostgreSQL

Учебный проект по Python (SkyPro).  
Задача: получить данные о компаниях и их вакансиях через API hh.ru,  
сохранить их в базу данных PostgreSQL и реализовать класс `DBManager` для работы с данными.

---

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/olganoskova200524/course_work_hh.git
cd course_work_hh
```

### 2. Установить зависимости через Poetry

```bash
poetry install
```

### 3. Настроить подключение к PostgreSQL

Создайте файл `database.ini` (он в `.gitignore`):

```ini
[postgresql]
host = localhost
user = postgres
password = ВАШ_ПАРОЛЬ
port = 5432
```

### 4. Запустить проект

```bash
poetry run python main.py
```

## Пример работы программы

```
===== МЕНЮ =====
1 - Компании и количество вакансий
2 - Все вакансии
3 - Средняя зарплата
4 - Вакансии выше средней зарплаты
5 - Поиск вакансий по ключевому слову
0 - Выход
```

---

## Возможности проекта

- Получение данных о работодателях и вакансиях с hh.ru (через публичный API).
- Автоматическое создание базы данных PostgreSQL и необходимых таблиц.
- Загрузка в БД информации о:
    - компаниях,
    - их вакансиях.
- Класс `DBManager` для работы с БД:
    - список всех компаний и количество вакансий у каждой,
    - все вакансии с указанием компании, зарплаты и ссылки,
    - средняя зарплата по вакансиям,
    - вакансии с зарплатой выше средней,
    - поиск вакансий по ключевому слову.
- Текстовое меню (CLI) для удобного взаимодействия.

## Замечания

- В проекте используется ограничение `max_pages=5` при загрузке вакансий,  
  чтобы не тянуть десятки тысяч записей от крупных работодателей (Сбер, Яндекс и т.д.).
- Для реального применения можно увеличить лимит.
